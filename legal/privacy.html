Настоящая Политика описывает, какие данные собирает и обрабатывает платформа Social Analytics AI («Сервис») при мониторинге и анализе публичных материалов в социальных сетях, включая Instagram через официальные API Meta.

1. Оператор

Оператор Сервиса: AI Leader.

2. Какие данные мы обрабатываем

  • данные учётных записей сотрудников (логин, хэш пароля, роль);
  • идентификаторы и публичные профили подключённых бизнес-аккаунтов;
  • публикации, метрики и публичные комментарии, полученные через официальные API;
  • результаты автоматического анализа текста (тональность, язык, темы);
  • технические журналы доступа (IP, время, ошибки API) для безопасности.

3. Цели обработки

Данные используются исключительно для предоставления аналитики организации: мониторинг упоминаний, оценка рисков, отчётность и улучшение качества Сервиса. Мы не продаём персональные данные третьим лицам.

4. Источники данных

Публичные данные социальных сетей загружаются через официальные API Meta (Instagram Graph / Facebook Graph) и иные разрешённые каналы платформ. Обрабатываются только данные, к которым у оператора есть законный доступ (собственный аккаунт или публичный business/creator профиль).

5. Хранение и защита

Данные хранятся на защищённых серверах с ограничением доступа по ролям. Токены доступа к API хранятся как секреты и не публикуются в исходном коде.

6. Передача третьим лицам

Для анализа текста Сервис может передавать фрагменты публичного контента провайдерам языковых моделей (например, через OpenRouter) в объёме, необходимом для выполнения запроса анализа. Передача осуществляется по защищённому каналу.

7. Права пользователей

Пользователь может запросить доступ, исправление или удаление данных, связанных с его учётной записью, по адресу safe.guard.uz@gmail.com или через страницу удаления данных.
