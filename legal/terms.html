Social Analytics AI — платформа мониторинга и аналитики социальных сетей для организаций. Доступ предоставляется авторизованным сотрудникам.

2. Допустимое использование

  • использовать Сервис только в законных целях и в рамках правил платформ;
  • не пытаться обходить ограничения API Meta и других сетей;
  • не собирать данные закрытых аккаунтов без законного основания;

3. Интеграции Meta / Instagram

Интеграция с Instagram выполняется через официальные API Meta. Пользователь подтверждает, что подключает только аккаунты и токены, которыми вправе распоряжаться, и соблюдает политики Meta.

4. Ограничение ответственности

Сервис зависит от доступности внешних API. Мы не гарантируем полноту данных, которые платформы не предоставляют (например, приватные профили или insights чужих аккаунтов).
